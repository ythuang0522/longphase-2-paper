\begin{abstract}
Read-based phasing reconstructs haplotypes from long reads, yet current phasers are built around single-nucleotide variants, weigh every read observation alike and report phase as an unqualified binary state, so that switch errors pass silently into every analysis built on them. Here we present \toolname, which co-phases SNVs, small indels, structural variants and allele-specific methylation in one weighted graph, calibrates each observation by base quality and sequence context, and attaches a phasing entropy to every variant. A compact graph neural network inspects high-entropy sites and withholds, but never flips, the phase assignments it predicts to be wrong. On HG002 nanopore data at 10--60$\times$ coverage, \toolname makes three- to fivefold fewer switch errors than WhatsHap and HapCUT2 while running six- to eightfold faster, lengthens haplotype blocks by up to 70\% through co-phasing, and shows that GRCh38-based benchmarks conceal most of the errors that a telomere-to-telomere truth set exposes. As a drop-in replacement for the LongPhase versions embedded in Clair3, ClairS, Severus and EPI2ME, it delivers longer, more accurate and self-assessed haplotypes to existing pipelines unchanged.
\end{abstract}

\begin{figure}[p]
  \centering
  \includegraphics[width=\textwidth]{fig1_overview}
  \caption{\textbf{Overview of \toolname.}
  \textbf{a}, Heterogeneous molecular evidence (SNVs, small indels, structural variants and 5mC calls) from the same long reads is integrated into a single haplotype-resolution problem.
  \textbf{b}, Weighted phasing graph. Allele nodes are connected by read-supported edges; evidence is calibrated by base quality and sequence-context reliability (homopolymers, tandem repeats, miscalled heterozygous sites in copy-number-altered regions) before multi-neighbour haplotype voting and read-based correction.
  \textbf{c}, Optional uncertainty correction. Per-variant phasing entropy selects loci for a graph neural network. Node features (phase evidence, variant type, genomic context, graph structure) and edge features (link strength, genomic distance, phase-set relation) of the window around the trigger variant (highlighted) enter two parallel branches: local graph attention, in which each node attends to its neighbours in the phasing graph (GATv2), and window-wide self-attention, in which every variant in the window attends to every other (Transformer). The two representations ($h_{\mathrm{local}}$, $h_{\mathrm{global}}$) are fused additively and passed through feed-forward layers (purple) that classify each variant as correctly phased or misphased; misphased variants are unphased (grey) and the affected phase set is split, preserving the genotype. Residual connections and layer normalization are omitted from the schematic (Methods; Supplementary Fig.~7).
  \textbf{d}, Outputs: two phased haplotypes carrying SNVs, an SV, a small indel and methylated (filled) or unmethylated (open) CpG sites, and reads haplotagged by the alleles they carry.}
  \label{fig:overview}
\end{figure}
