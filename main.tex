\begin{abstract}
Read-based phasing resolves haplotypes from long reads, yet current methods phase only single-nucleotide variants, weigh all read evidence equally and report no measure of confidence, so that switch errors propagate unnoticed into downstream analyses. Here we present \toolname, which co-phases SNVs, indels, structural variants and allele-specific methylation in a single weighted graph, calibrates every observation by base quality and sequence context, and attaches a phasing entropy to each variant. An optional graph neural network inspects high-entropy sites and removes unreliable phase assignments without altering genotypes. On HG002 nanopore data, \toolname reduces switch errors 3--5-fold relative to WhatsHap and HapCUT2 while running 6--8 times faster, extends haplotype blocks by up to 70\% through co-phasing, and reveals that GRCh38-based benchmarks conceal most of the errors exposed by telomere-to-telomere truth sets. \toolname is a drop-in replacement for the version already embedded in Clair3, ClairS, Severus and EPI2ME workflows.
\end{abstract}

  \includegraphics[width=\textwidth]{fig1_overview}
  \caption{\textbf{Overview of \toolname.}
  \textbf{a}, Heterogeneous molecular evidence (SNVs, small indels, structural variants and 5mC calls) from the same long reads is integrated into a single haplotype-resolution problem.
  \textbf{b}, Weighted phasing graph. Allele nodes are connected by read-supported edges; evidence is calibrated by base quality and sequence-context reliability (homopolymers, tandem repeats, miscalled heterozygous sites in copy-number-altered regions) before multi-neighbour haplotype voting and read-based correction.
  \textbf{c}, Optional uncertainty correction. Per-variant phasing entropy selects loci for a graph neural network that combines local attention over the phasing graph (GATv2) with window-wide attention (Transformer); variants predicted to be misphased are unphased and the affected phase set is split, preserving the genotype.
  \textbf{d}, Outputs: phased VCFs for all variant classes and haplotagged alignments.}
  \label{fig:overview}
\end{figure}
