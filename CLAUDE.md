# CLAUDE.md

## What this is

The LaTeX manuscript for LongPhase 2 (Nature-style article + Supplementary Information). Not a software project: the deliverables are `main.pdf` and `Supplementary.pdf`. `README.md` holds the current state (layout, the further-phaser comparison, the open items before submission and the tag vocabulary); `notes/log/` holds the dated change log (todo triage, review history, known text↔code discrepancies), one file per change, indexed newest first in `notes/log/README.md`. Read both before editing any claim. Log each change as a new file in notes/log/ (`YYYY-MM-DD-short-slug.md`, title as H1, plus one line at the top of `notes/log/README.md`). Update README only when the state of the manuscript changes.

## Build

```sh
make                 # main.pdf + Supplementary.pdf (latexmk, naturemag.bst; rebuilds Fig. 1 from source)
make wordcount       # texcount on the Introduction only
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex   # one document
```

Toolchain on this machine: TeX Live 2025 (`latexmk`, `texcount`, `naturemag.bst`), `rsvg-convert` (Homebrew), `python3` (miniforge). Build artifacts (`.aux`, `.log`, `.fdb_latexmk`, …) are gitignored; the PDFs are committed.

## Manuscript conventions

- Two independent documents: `main.tex` (inputs `sections/*.tex`) and `Supplementary.tex` (monolithic), sharing `references.bib` and duplicating the macro block (`\toolname`, `\longphase`, `\whatshap`, `\hapcut`, `\todo`). Change macros in both files.
- Cross-references between the two documents are literal numbers ("Supplementary Fig.~6", "Supplementary Table~3"), not `\ref`. Renumbering a supplementary figure or table requires a grep sweep of `sections/*.tex` and `Supplementary.tex`.
- `\todo{…}` renders red and is reserved for items that block submission. Everything non-blocking lives in `%  [tag]` source comments placed next to the paragraph they concern (`grep -n '^%  \[' sections/*.tex Supplementary.tex`); the tag vocabulary is listed in README. Do not promote comments to `\todo` or vice versa without reason.
- Figure legends follow Nature Methods practice: a bold title plus one short sentence (two at most) per panel, well under ~150 words for a schematic figure. Say what each panel shows, not how it was drawn or implemented; architecture, feature lists and edge cases belong in Methods or the Supplementary figure the legend points to. Fig. 1 was cut from ~480 to ~100 words on the author's instruction (2026-09-24).
- Results uses six unnumbered `\subsection*` headings, all declarative sentences, with no run-in `\paragraph` headings (author-approved consolidation, 2026-10-10). Preserve the comparison-then-internal-modules order through the final section's opening transition.
- Bibliography: superscript natbib with `naturemag.bst`. Several `.bib` entries were hand-repaired from raw Crossref HTML; check new entries for `<scp>`/`<i>` in titles.

## Register (Nature Methods) — mandatory

- Write as a Nature Methods paper, not a technical note or a software manual.
- No process, provenance or command sentences in the text ("we scored with the pre-release draft", awk commands). Keep provenance in `%  [provenance]` comments or `notes/`.
- Abstract: 150 words or fewer; no version numbers; no list of programs; lead with the advance.
- Results: describe the trend across all plotted coverages, not only 10× and 60×. Write from the figure.

## Figure changes — mandatory

- Agree the message and the layout with the author before a redesign (options or a draft PNG).
- In the same turn as any figure change, update: panel and row titles, keys, the legend, every `Fig.~N` reference in `sections/*.tex` and `Supplementary.tex` (literal numbers, so grep; see Manuscript conventions), and a new file in `notes/log/`. Fix stale labels; do not list them as open.
- Panel titles name the platform (nanopore / PacBio HiFi).
