## What this is

The LaTeX manuscript for LongPhase 2 (Nature-style article + Supplementary Information). Not a software project: the deliverables are `main.pdf` and `Supplementary.pdf`. `README.md` is the authoritative status log (todo triage, review history, known text↔code discrepancies) — read it before editing any claim, and update it when the state of the manuscript changes.

## Build

```sh
make                 # main.pdf + Supplementary.pdf (latexmk, naturemag.bst; rebuilds Fig. 1 from source)
make wordcount       # texcount on the Introduction only
make clean           # latexmk -C + bbl/blg
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex   # one document
```

Toolchain on this machine: TeX Live 2025 (`latexmk`, `texcount`, `naturemag.bst`), `rsvg-convert` (Homebrew), `python3` (miniforge). Build artifacts (`.aux`, `.log`, `.fdb_latexmk`, …) are gitignored; the PDFs are committed.

## Figures

- **Fig. 1** is fully generated: edit `figures-source/make_fig1.py`, never the SVG. `make` regenerates `figures/fig1_overview.svg` → `.pdf`.
- **Supplementary Figs. 1–8** are generated by `figures/supp/make_supp_figs.py`, which must be run from inside `figures/supp/` (it writes SVGs to cwd). The Makefile converts the SVGs to PDF but does *not* run the script — run it by hand after editing. Supplementary Fig. 9 (calibration) is a placeholder with no artwork.
- **Figs. 2–6** are raster PNGs exported from a pptx with no plotting source; their numbers are plot-read (see README item 9). `figures/supp/imagen/` holds earlier AI-generated concept drafts, not used in the build.
- Palette and glyph conventions are shared between `make_fig1.py` and `make_supp_figs.py` (haplotype 1 `#1687C9`, haplotype 2 `#DC2B23`); keep new panels consistent with both.

## Manuscript conventions

- Two independent documents: `main.tex` (inputs `sections/*.tex`) and `Supplementary.tex` (monolithic), sharing `references.bib` and duplicating the macro block (`\toolname`, `\longphase`, `\whatshap`, `\hapcut`, `\todo`). Change macros in both files.
- Cross-references between the two documents are literal numbers ("Supplementary Fig.~6", "Supplementary Table~3"), not `\ref`. Renumbering a supplementary figure or table requires a grep sweep of `sections/*.tex` and `Supplementary.tex`.
- `\todo{…}` renders red and is reserved for items that block submission. Everything non-blocking lives in `%  [tag]` source comments placed next to the paragraph they concern (`grep -n '^%  \[' sections/*.tex Supplementary.tex`); the tag vocabulary is listed in README. Do not promote comments to `\todo` or vice versa without reason.
- Section headings use `\subsection*`/`\paragraph` (unnumbered, Nature style); Results subsection titles are declarative sentences.
- Bibliography: superscript natbib with `naturemag.bst`. Several `.bib` entries were hand-repaired from raw Crossref HTML; check new entries for `<scp>`/`<i>` in titles.
