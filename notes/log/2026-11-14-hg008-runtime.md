# HG008 runtime re-measured with the SSD protocol (issue #11)

The runtimes of the HG008 accuracy runs (`notes/hg008_validation/`) are not comparable with Supplementary Table 11, because other jobs shared the machine. They were re-measured on 2026-11-13/14 with the manuscript's SSD protocol (`2026-10-28-runtime-ssd.md`): seed 1 at 10, 20 and 30×; LongPhase v2.1.2 with GNN (24 and 1 threads) and with `--disableGNN` (24 threads), WhatsHap and HapCUT2; idle machine, page cache dropped before every run, one run at a time.

Added `notes/hg008_validation/scripts/timing/run_timing.sh`, `results/hg008_times.tsv` and `results/hg008_timing.log`, and the runtime table to the Runtime section of `notes/hg008_validation/README.md`. Every re-timed LongPhase 2 and WhatsHap output is identical to the accuracy run. LongPhase 2 with GNN and 24 threads takes 13–26 s, WhatsHap 10–74 min and HapCUT2 12–38 min (46–169× faster than WhatsHap). The results were also posted on issue #11. No manuscript text changed.
